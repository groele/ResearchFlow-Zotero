# ResearchFlow Companion v8.3.0

## Share-card templates

- Journal Cover: title-first serif typography, blue gradient paper and a cover band.
- Conference Poster: large title, teal gradient, margin accent and boxed metrics.
- Lab Archive: journal-first hierarchy, warm paper and alternating milestone rows.
- All seven existing card styles remain available. Privacy settings and data schema are unchanged.

## Verification

The browser suite covers 120 English/Chinese layout cases across ten styles, privacy controls, real PNG download, zoom and mobile preview. Full regression and MV3 smoke checks are run before publication.

## Local installation

After updating an unpacked extension directory, reload the extension in chrome://extensions and reopen its workspace. Publishing a GitHub Release does not update an existing unpacked installation automatically.
