# ResearchFlow Companion v7.3.0

## Overview

This release improves the local submission-journey sharing workflow and refreshes the multi-cloud settings workspace.

## Added

- Added a share shortcut to submission pipeline cards.
- Added local share-image generation with visibility controls and mobile image presets.

## Changed

- Reworked share cards around a clearer mobile-first hierarchy, with the journal name as the primary visual anchor.
- Improved the share preview to fit portrait cards without desktop scrolling and compact the controls on mobile screens.
- Redesigned Multi-Cloud Settings with grouped cards and consistent blue/cyan workspace styling.

## Compatibility

Backward compatible; no migration required. Images are generated locally and are not uploaded unless the user explicitly shares them.

## Verification

- JavaScript syntax check passed.
- Options UI and localization tests passed.
- Desktop and mobile browser previews verified.
