# ResearchFlow for Zotero 10.0.2

## 侧边栏图标模式 / Icon-only item-pane navigation

- Zotero 文献条目右侧的 ResearchFlow 侧边栏入口现在只显示图标。
- 完整标题仍显示在展开后的内容区标题中。
- 悬停图标仍提供中英文 tooltip，并保留无障碍名称。
- 修复窄侧栏中文字被挤压成竖排、遮挡其他入口的问题。

The ResearchFlow item-pane navigation entry now displays only its icon. The full
title remains in the expanded section header, while the icon keeps a localized
tooltip and accessible name. This prevents the title from wrapping vertically
and obscuring neighboring navigation entries in narrow sidebars.
