# ResearchFlow for Zotero 9.1.5 — Journal identity and numbering

- Strengthened submission numbers with bright blue rounded badges, white medium-weight digits, and flexible widths for multi-digit values.
- Increased journal-label size and weight, with airy blue pill surfaces and small coral accents for a fresher appearance in light and dark themes.
- Matched the submission list's journal headings to the dashboard hierarchy, with two-line wrapping and full-name tooltips for long names.
- Preserved submission ordering, data format, shared editing, toolbar behavior and active timeline animation.

## Install

Install researchflow-zotero-9.1.5.xpi from Zotero's add-on manager and restart Zotero.
