# ResearchFlow for Zotero 10.0.4

## 插件市场窗口 / Plugin Market window

ResearchFlow 工具栏按钮现在只添加到 Zotero 主文献窗口的专用工具栏，不再出现在“插件市场”等其他窗口的工具栏中。安装更新后重启 Zotero，即可清除已经显示在旧窗口中的按钮。

The ResearchFlow toolbar button is now inserted only into a dedicated Zotero library toolbar. It no longer appears in toolbars belonging to other windows, including Plugin Market. Restart Zotero after updating to remove buttons already present in older windows.
